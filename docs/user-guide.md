# 使用教程

从创建第一个连接开始，逐步使用终端、文件、监控和 AI 助手。教程随程序安装，无需连接外网即可阅读。

## 第一次连接服务器

1. 在左侧“分组与服务器”中新建分组，可用父分组组织不同环境。
2. 在分组下添加主机，填写名称、IP 或域名、SSH 端口（通常为 `22`）。
3. 为主机添加账户，填写用户名，并配置密码或私钥；服务器和账户均需启用。
4. 选择账户建立连接，即可使用终端与监控、文件、进程和存储管理。

分组、主机和账户支持编辑、拖拽排序与移动。删除分组或主机会级联删除其下关联配置，请先确认范围，必要时通过“数据管理”导出备份。

## 终端与多个标签

单击账户切换连接；双击账户，或在账户的更多菜单选择“新建终端”，可为同一账户重复打开独立终端。标签显示主机名称、IP 和账户，便于区分。

| 操作 | 使用方法 |
| --- | --- |
| 搜索终端文字 | 聚焦终端后按 `Ctrl+F`，在搜索栏查找输出 |
| 复制选中文字 | `Ctrl+C` 或 `Ctrl+Insert`；未选中文字时 `Ctrl+C` 发送中断 |
| 粘贴 | `Ctrl+Shift+V` 或 `Shift+Insert`，也可使用终端右键菜单 |
| 查看快捷操作 | 在终端区域单击右键 |
| 区分连接方式 | 查看终端顶栏右上角的 SSH / tmux 标识 |

远端 Linux 安装 `tmux` 后，可使用 tmux 保留远端终端会话。普通 SSH 连接断开后无法保留现场；刷新网页后仍需重新连接，独立标签不会全部自动恢复。剪贴板能力受浏览器权限及访问方式影响，局域网 HTTP 地址可能需要手动选择和复制。

## 浏览文件与传输

文件区位于终端下方，可调整终端与文件区的高度比例。进入目录后，可以上传、下载、重命名或删除文件，文件夹也支持上传和下载。

点击“传输列表”查看当前服务器下的传输任务、进度、速度及错误。切换页面不会取消本页仍在执行的任务；上传按块发送，适合大文件，仍需确保两端磁盘空间充足。

刷新或关闭浏览器会中断页面内传输，目前不支持断点续传。重新打开后，历史记录可显示最后进度，但不能自动续传；“结果待确认”需要检查远端文件。由浏览器接管的下载，请在浏览器下载列表查看实际进度与结果。

## 监控面板与自定义卡片

监控区显示 CPU、内存、网络、磁盘、inode 和可用的 GPU 等指标。卡片可拖拽排序，使用卡片上的放大按钮查看详情。

1. 在监控区切换或新增面板，按 `Ctrl+Space` 可循环切换面板。
2. 打开监控设置，调整采样间隔、暂停状态、趋势范围以及当前面板显示的卡片。
3. 在设置右侧管理自定义脚本卡片：填写名称、类型和脚本，参考界面提供的 JSON 输出框架。
4. 保存后观察卡片输出；出现脚本错误时检查命令权限、依赖及输出格式。

配置按账户保存，各面板可选择不同卡片，新卡片默认加入当前面板。每个账户最多 20 个自定义脚本卡片，支持文本、状态、数值、进度、JSON 表格、折线、柱状和饼图等类型。脚本超时不得超过采样间隔的 60%。

折线图可按时间保存连续采样；历史趋势存放在当前浏览器，按选择的 5、15 或 30 分钟范围裁剪。暂停、断开或离开页面期间不补采，速率指标可能需要连续两次有效采样。图表显示等待数据时，先检查连接、采样状态与脚本输出。

## AI 助手

点击顶栏“AI 助手”或按 `Ctrl+Shift+K` 打开。助手支持拖拽移动、调整大小和全屏，操作其他页面时可以保持打开；默认不在启动时自动弹出，可在设置中更改。

1. 打开助手的“设置 → 厂商配置”，填写 OpenAI 兼容厂商的地址、模型和 API Key。地址通常包含 `/v1`，模型需支持工具调用。
2. 选择已保存的模型及操作账户，确认授权模式。
3. 输入任务，按 `Enter` 发送，按 `Ctrl+Enter` 换行。
4. 查看流式回复和工具执行结果，点击复制按钮可复制消息或代码。

默认“全部权限”会自动执行已开放工具，包括写操作；切换为询问模式后，写操作需要确认。可以要求 AI 管理分组、主机、账户及监控面板和卡片，排查进程、执行命令、操作文件或编写脚本。任务中请说明目标账户和面板，例如：“在当前账户的巡检面板创建 CPU 时间趋势卡片”。

“历史”可恢复之前的对话，切换已连接账户会加载对应账户的最近会话。历史会话可在“数据管理 → 清除数据”中清理。附件是临时数据，过期或服务重启后需重新选择；发送的消息、附件和工具结果会交给所选 AI 厂商。

## 脚本与定时任务

在“脚本与定时任务”页面新建脚本，选择执行账户并填写 Shell 内容。先手动执行，检查输出与退出码，再设置定时规则和启用任务。执行历史可查看日志、状态及结束运行。

定时任务由 Doumi Shell 服务端独立执行：浏览器不必打开，也不要求提前建立终端连接；后台会使用保存的账户凭据建立 SSH 连接。部署程序必须持续运行，目标机器需可达。脚本不主动输出内容时，日志可能为空，请结合退出码和实际效果判断。

## 进程与存储管理

“进程”页面可按 PID、用户或命令过滤，查看完整命令，按需正常停止或强制停止进程。

“存储管理”可扫描目录占用和大文件，点击子目录继续深入，也可以定位到文件区操作。扫描大目录可能需要较长时间；先选择具体目录能缩小范围。

## 配置备份与清理

在“数据管理 → 配置导入导出”导出备份，保存分组、主机、账户、脚本及监控配置。包含凭据的备份请妥善保管，优先使用加密导出；导入后核对数量及配置。

“清除数据”可按类型和时间范围清理历史。请先预览影响范围，清理历史不会代替配置备份。需要备份整个数据目录时，先停止程序，并同时保留数据库和 `master.key`，否则已保存的凭据无法解密。

## 部署、升级与常见问题

Windows 使用 MSI 安装包；Linux x64 解压后使用 Java 17 运行 `run-linux.sh`。Linux 部署后，局域网设备可通过 `http://服务器IP:端口/` 访问，需放行对应端口。默认端口为 80，可用 `DOUMI_PORT` 修改，用 `DOUMI_DATA_DIR` 指定独立数据目录。

“关于 → 检查更新”只检测并提供下载，不会自动安装。Windows 先在托盘退出旧程序，再安装新 MSI；Linux 停止服务后替换程序并重启，保留原数据目录、密钥和启动参数。升级会中断当前连接和正在运行的任务，应先等待任务结束。

| 情况 | 检查方法 |
| --- | --- |
| 网页打不开 | 确认服务运行、地址和端口正确，检查防火墙及端口占用 |
| SSH 连接失败 | 核对目标地址、端口、账户凭据及网络连通性 |
| 没有监控数据 | 检查连接、暂停状态、卡片开关及脚本输出；速率指标等待后续采样 |
| AI 请求失败 | 检查部署机器到厂商的网络、Base URL、模型工具调用支持和密钥 |
| 更新后界面仍旧 | 确认升级的是部署机器上的程序，再刷新网页加载新资源 |
