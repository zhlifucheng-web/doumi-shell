# 终端目录跟随与上传文件归属

SFTP 面板默认开启“跟随终端目录”。终端执行 `cd`、`su -` 或 `exit` 后，面板会跟随检测到的实际工作目录。手动进入目录会关闭跟随，也可以随时重新开启；此开关保存在浏览器中。

目录跟随通过现有 SSH 连接上的独立只读 exec 通道读取 Linux `/proc`。每次检测完成后间隔 1 秒再次检测，不向交互终端输入命令，也不修改 Shell 配置。打开文件查看器或编辑器时，暂缓自动切换目录；关闭后应用最近检测到的目录。隐藏面板、切换会话或关闭面板时取消当前检测并停止轮询。

## 文件操作身份

终端用户和文件操作身份分别显示。SFTP 始终使用最初登录的 SSH 用户：例如以 root 登录后在终端切换到普通用户，SFTP 仍保留 root 的原有权限，包括修改文件属性的能力。切换终端用户不会重新登录或自动提升、降低文件操作权限。

嵌套 SSH、tmux/screen、无法读取进程信息、目录被删除或上下文正在变化时，面板提示暂不可检测并保留现有目录，不根据命令文字或提示符猜测目录。远端需要 Linux `/proc` 和 Python 2.7 或 Python 3；不满足条件时，原有 SFTP 功能仍可使用。

## 上传归属

“上传后归属终端用户”默认关闭。启用后，上传任务采用入队时最近一次检测确认的终端 UID/GID；同时固定会话和绝对目标目录。之后切换标签、用户或目录不会改变已入队任务的目标和归属。无法确认 UID/GID 时不允许以此选项发起上传。

普通文件、拖放、文件夹和 ZIP 上传均支持此选项。文件夹仅调整本次新建目录和上传文件的归属，不修改已存在目录。所有归属调整通过原登录身份的 SFTP 完成，需要该身份有对应权限。

默认覆盖文件时先保留原文件的 owner、group 和 mode，再原子替换；无法保留属性或服务端不支持安全覆盖时，保留原文件并报告失败。显式归属调整在文件成功提交后执行，并清除 setuid/setgid 位。若调整失败，显示“文件已上传”的成功状态及独立警告，不自动重复上传。

该选项采用最近确认的身份快照，不承诺与终端稍后发生的用户切换同步。如果上传后再次切换用户，已完成文件的归属不会自动改变。
