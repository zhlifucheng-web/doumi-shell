# Doumi Shell

**让运维更简单，让 AI 直接帮你干活。跨平台部署一次，局域网内打开浏览器即可使用。**

Doumi Shell 是一款支持 Windows 和 Linux 的 SSH 运维工作台。双击账户连接服务器，左侧看监控、右上用终端、右下传文件，常用操作在同一界面完成，减少工具切换和重复输入。排查进程、检查磁盘、执行脚本、设置定时任务，都有直观的操作入口。

**把需求告诉 AI，让它读取现场、调用工具并完成操作。** AI 助手能执行命令、管理文件、维护主机与账户、编写脚本及管理定时任务，还能创建和调整业务监控卡片。对话中可查看调用参数、执行结果和历史记录，也可设置写操作逐项确认；操作页面时，对话窗口继续保留。

**局域网部署一次，多设备随时使用。** 服务可部署在 Windows 或 Linux 上，局域网内的 Windows、Linux、macOS 电脑使用现代浏览器访问同一个地址即可，无需在每台电脑重复安装客户端。

Windows MSI 自带运行环境，Linux 部署需要 Java 17；访问端只需浏览器，无需安装 Java、Node.js 或 Doumi Shell。程序升级在部署机器上完成，其他设备重新打开网页即可使用新版界面。

## 亮点功能

### 日常运维，少切换、少重复

分组集中管理服务器与账户，双击账户即可打开终端，同一账户也能并行打开多个标签。一边观察资源曲线，一边执行命令、浏览目录和传输文件；查看进程、定位大文件、执行已保存脚本，都可从工作台进入。常用脚本保存后重复使用，周期性工作交给定时任务，执行输出和退出状态可随时追查。

### 跨平台部署，局域网内处处使用

一台常开的 Windows 电脑或 Linux 服务器，就能成为局域网中的 SSH 运维工作台。部署机器统一保存主机、账户和脚本等业务配置，换一台能访问该地址的电脑，打开浏览器即可继续使用这些配置。SSH 连接和定时任务由部署机器执行，部署机器需要能访问目标服务器。

### AI 助手，从排查到执行都能参与

AI 助手可读取服务器资源、排查进程、执行命令和管理文件，也能修改分组、主机和账户配置，管理脚本与定时任务。支持 OpenAI 兼容厂商、多模型切换、流式 Markdown、附件分析和历史会话，操作业务页面时可以保持对话窗口打开。

可以直接描述任务，例如：

- **“检查当前服务器内存和磁盘占用，找出占用最高的进程。”** 让 AI 读取实际资源与进程信息，结合工具返回结果协助排查。
- **“在当前账户的巡检面板创建 JVM 堆内存趋势卡片。”** 让 AI 选择卡片类型、编写采集脚本，并通过接口保存配置。
- **“编写一个每天凌晨执行的巡检脚本，并配置定时任务。”** 让 AI 编写脚本、保存计划，执行后可查看记录与输出。

支持 OpenAI 兼容接口，可按需要配置厂商并切换模型。可选择写操作逐项确认或全部权限自动执行。

### 让监控贴合你的业务

每个账户可配置多个监控面板，分别选择卡片和排序，按 `Ctrl+Space` 快捷切换。内置 CPU、内存、Swap、网络、磁盘、inode 及可用的 GPU 指标，支持卡片拖拽和放大查看。

自定义脚本输出约定 JSON，即可展示**状态文本、数值、进度、JSON 表格、折线图、柱状图或饼图**；每个账户最多 20 张自定义脚本卡片。折线图支持连续采样形成时间趋势。

### 多终端、文件与监控同屏协作

同一服务器账户可重复打开独立终端标签，标签以主机名称、IP 和账户区分。双击账户即可新建终端，支持 `Ctrl+F` 搜索、右键快捷操作和复制粘贴。远端 Linux 安装 tmux 后可使用持久终端会话，顶栏明确显示 SSH / tmux 连接方式。

文件管理直接集成在终端下方，支持目录浏览、文件与文件夹传输、压缩传输、重命名和删除。大文件上传按块发送、下载流式输出。

### 浏览器关闭，定时任务照常运行

脚本支持语法高亮、交互式 Cron 设置和未来执行时间预览。定时任务由服务端使用保存的凭据独立建立 SSH 连接，不依赖网页保持打开或已有终端连接。

### 漂亮的界面，也保留操作习惯

支持浅色、深色、跟随系统及自定义背景，终端、监控、AI 助手和弹窗使用统一主题。监控与文件区域可调整尺寸，AI 助手可拖动、缩放或全屏。

## 下载与安装

支持 **Windows 10 / 11（64 位）** 和 **Linux x64**。

### Windows

1. 从 [GitHub Releases](https://github.com/zhlifucheng-web/doumi-shell/releases) 下载最新版本的 `Doumi Shell-*.msi` 并双击安装。
2. 选择安装目录，按需创建桌面和开始菜单快捷方式。
3. 安装完成时勾选 **Open Doumi Shell in browser now**，或稍后通过快捷方式启动。
4. 程序就绪后自动打开浏览器，也可以访问 **http://localhost/**。

### Linux

1. 在 [GitHub Releases](https://github.com/zhlifucheng-web/doumi-shell/releases) 下载最新版本的 `doumi-shell-*-linux-x64.tar.gz`。
2. 解压并进入目录，确认已安装 Java 17，然后运行启动脚本：

   ```bash
   tar -xzf doumi-shell-<版本>-linux-x64.tar.gz
   cd doumi-shell-<版本>
   chmod +x run-linux.sh
   ./run-linux.sh
   ```

3. 在部署机器上访问 **http://localhost/**。

### 局域网部署

1. 在一台机器上安装并启动 Doumi Shell，保持程序运行，确认该机器能通过 SSH 访问目标服务器。
2. 在部署机器的防火墙放行实际使用的 TCP 端口，默认是 80。
3. 在局域网其他电脑的浏览器中打开 `http://部署机器局域网IP:端口/`。

## 第一次连接服务器

1. 在左侧“分组与服务器”中创建分组。
2. 在分组下添加主机，填写服务器地址和 SSH 端口，通常为 22。
3. 为主机添加账户，配置用户名及密码或私钥。
4. 选择账户建立连接，即可使用终端、文件、监控和存储管理。

## AI 助手

点击顶栏 **AI 助手 → 设置 → 厂商配置**，填写名称、Base URL、模型和 API Key。Base URL 通常包含 `/v1`，例如 `https://你的厂商地址/v1`；也支持完整的 `/chat/completions` 地址。模型需要支持 `tools` / function calling。

对话可以查看服务器资源、文件、进程、存储和脚本，创建及修改分组、主机与账户，也可以执行命令、编辑文件、管理定时任务及导入导出配置。

## 数据位置

- Windows 数据保存在 `%LOCALAPPDATA%\DoumiShell\data`
- Linux 默认保存在启动目录的 `data/`，也可通过 `DOUMI_DATA_DIR` 指定
- 日志位于数据目录的 `logs` 子目录
